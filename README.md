## Featured projects

### [Trade Settlement Simulator](https://github.com/SteamOon/trade-settlement-simulator)

A post-trade clearing and settlement simulator built with **Kotlin, Spring Boot, Spring Data JPA, and PostgreSQL**, following Domain-Driven Design principles.

- Models trade capture, counterparty confirmation matching, and atomic **Delivery Versus Payment (DVP)** settlement
- Uses double-entry ledger accounting, idempotency, audit trails, and failure recovery
- Includes REST APIs and transaction-safe processing
- Supported by unit, integration, and end-to-end testing with **Testcontainers** and Docker

### [Webserv](https://github.com/SteamOon/webserv)

An **HTTP/1.1 web server in C++98** built from scratch.

- Implements configuration and request parsing, CGI execution, and concurrent connections
- Uses non-blocking I/O with `epoll`
- Developed collaboratively with Git best practices and stress testing

### [MiniRT](https://github.com/SteamOon/miniRT)

A C ray tracer rendering 3D scenes with spheres, planes, cylinders, lights, and a camera.

- Implements lighting, shadows, reflections, and camera transformations from mathematical first principles
- Demonstrates practical geometry, vector mathematics, memory management, and graphics programming

### [MiniShell](https://github.com/SteamOon/minishell) · [Philosophers](https://github.com/SteamOon/philosophers) · [Fract-ol](https://github.com/SteamOon/fractol)

A selection of systems-focused projects covering shell behaviour and process execution, thread synchronization with mutexes, and interactive Mandelbrot and Julia fractal rendering.
